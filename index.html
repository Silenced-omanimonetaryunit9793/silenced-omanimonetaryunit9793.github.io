💡 What is git-iterm2?

Imagine you're working in your terminal (iTerm2 on a Mac). You're typing commands, moving files, running scripts. But when you want to check your Git changes — what's modified, what needs to be staged, which branch you're on — you have to switch to a different app or type a bunch of git status commands over and over.

git-iterm2 fixes that by showing you a live panel right inside your terminal. It's exactly like the Source Control panel in VS Code—but it follows whatever folder you're currently working in. You can see changed files, stage them, unstage them, view diffs, look at branches, see the commit graph, and manage stashes—all without leaving your terminal.

✨ Key Features

  • 🔄 Session-Aware — It automatically detects which repository you're in. No manual switching. Just cd into any folder with git, and the panel updates.
  • 📝 Status & Staging — See modified, untracked, staged files in a clear list. Stage or unstage with one click.
  • 🔍 Inline Diffs — Click any file to see exactly what changed, line by line. No more switching to a GUI.
  • 🌿 Branches & Graph — View all branches, see the commit history graph visually, and switch branches with ease.
  • 📦 Stash Management — Save your work-in-progress, list all stashes, apply or drop them—all from your terminal.

🚀 Getting Started

  1. Download the application: Visit this link to download the application. This page will give you the latest version of git-iterm2.
  2. Open iTerm2: git-iterm2 lives inside iTerm2. If you don't have iTerm2 installed, you'll need to install it first (it's a free, popular terminal app for macos).
  3. Install git-iterm2: Follow the simple installation instructions provided onthe download page. It typically involves running a one-line command in your terminal.
  4. Start using it: Once installed, you'll see the git panel appear in your iTerm2 window. Navigate to any Git repository folder, and the panel will automatically show you all the changes, branches, and stashes.

💡 Tip: The panel follows your current working directory. So just cd into any project, and you're good to go.

🖥️ System Requirements

  • 🍏 macOS (iTerm2 is a mac-only app)
  • 🖥️ iTerm2 version 3.4 or newer
  • 🐙 Git version 2.20 or newer (check with git --version)

🛠️ Troubleshooting & FAQ

Q: I don't see the panel in iTerm2. What should I do?

Make sure you've installed git-iterm2 correctly byfollowing the instructions on the download page. Also, ensure you're inside a Git repository folder (one that has a .git folder).

Q: The panel looks cluttered. Can I customize it?

The panel is designed to be minimal,and it only shows the most relevant information for your current state. As you stage files or switch branches, it updates automatically.

Q: Does it work with other terminals?

Currently, it's specially built for iTerm2 on macOS. The project is open source, soyou may find community contributions for other terminals inthe future.
